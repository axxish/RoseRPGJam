# Product Requirements Document (PRD) for Campaign Format

## Overview

The campaign format defines the structure and data required to load and play a campaign in the roguelike RPG. Each campaign is self-contained and defines its own items, entities, tiles, structures, rooms, and levels.

---

| **ID** | **Description**                                                                                                                                                                                                                         |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ITEMS-1      | Items are objects that can be equipped or used by entities.<br />Items must have a name, description, attributes, and slot restrictions.                                                                                                     |
| ITEMS-2      | Items must specify a name.<br />Name must be a string.                                                                                                                                                                                        |
| ITEMS-3      | Items must specify a description.<br />Description must be a string.                                                                                                                                                                          |
| ITEMS-4      | Items must specify attributes that modify stats defined in `stats.yaml`. <br />Attribute modification must be explicitly categorized into three states: when in inventory, when equipped, and upon consumption.                             |
| ITEMS-5      | Items must specify slot restrictions, if they can be equipped<br />Restrictions include slot type and maximum items per slot.                                                                                                                 |
| ITEMS-6      | Slots must be predefined in the campaign.<br />Slots must specify a name and maximum capacity.                                                                                                                                                |
| ITEMS-7      | Equippable items must specify equip requirements.<br />Requirements include minimum attributes like STRENGTH or INSIGHT.                                                                                                                      |
| ITEMS-8      | Slots must be predefined in the campaign.<br />Slots must specify a name and maximum capacity.                                                                                                                                                |
| ITEMS-9      | Items can affect base stats or additional stats.<br />Examples include PHYSICAL_DAMAGE, ARMOR, or CRITICAL_CHANCE. <br />These effects must be categorized based on whether they apply when in inventory, when equipped, or upon consumption. |
| ITEMS-10     | Items can be consumable. Consumable items must have a consumable tag.<br />If an item is consumable, the attributes it affects upon consuming must be specified.                                                                              |
| ITEMS-11     | Items can be equippable. Equippable items must have an equippable tag. Attributes affected when equipped must be specified.                                                                                                                   |
| ITEMS-12     | Items can be both equippable and consumable.<br />In such cases, attributes affected upon consuming and when equipped must be written in separate YAML lists.                                                                                 |
| ENTITIES-1   | Entities are characters or creatures in the game. Entities must have a name, description, base stats, and sprite.                                                                                                                             |
| ENTITIES-2   | Entities must specify a name. Name must be a string.                                                                                                                                                                                          |
| ENTITIES-3   | Entities must specify a description. Description must be a string.                                                                                                                                                                            |
| ENTITIES-4   | Entities must specify base stats. Base stats must reference `stats.yaml`.                                                                                                                                                                   |
| ENTITIES-5   | Entities must specify a sprite. Sprite must reference `graphics.yaml`.                                                                                                                                                                      |
| ENTITIES-6   | Optional AI types are predefined in the game engine. Campaigns cannot define custom AI types.<br />AI type will decide the entitie's turn if the entity is not player controlled.                                                             |
| ENTITIES-7   | Entities must specify XP and Levels. XP tracks experience points, and Levels are derived from XP.                                                                                                                                             |
| ENTITIES-8   | Entities may have an oblique tag. Oblique entities can be walked through (they don't prevent walking).                                                                                                                                        |
| ENTITIES-9   | Entities may specify the amount of INVENTORY_SLOTS, however if none is specified, the enitity will be assumed to have none.                                                                                                                   |
| ENTITIES-10  | Entities may have items equipped in the appropriate slots in the config file.                                                                                                                                                                 |
| TILES-1      | Tiles are the building blocks of rooms and levels. Tiles must have a name, walkable flag, and sprite.                                                                                                                                         |
| TILES-2      | Tiles must specify a name. Name must be a string.                                                                                                                                                                                             |
| TILES-3      | Tiles must specify whether they are walkable. Walkable must be a boolean.                                                                                                                                                                     |
| TILES-4      | Tiles must specify a sprite. Sprite must reference `graphics.yaml`.                                                                                                                                                                         |
| STRUCTURES-1 | Structures are collections of tiles that can spawn inside rooms. Structures must have a name, a size and tile composition.                                                                                                                    |
| STRUCTURES-2 | Structures must specify a name. Name must be a string.                                                                                                                                                                                        |
| STRUCTURES-3 | Structures must specify tile composition. Composition includes a list of tiles and their arrangement.                                                                                                                                         |
| ROOMS-1      | Rooms are areas within levels. Rooms must have size, tiles, and spawn probabilities for entities and items.                                                                                                                                   |
| ROOMS-2      | Rooms must specify minimum and maximum size. Size includes width and height.                                                                                                                                                                  |
| ROOMS-3      | Rooms must specify a floor tile. Floor tile must reference `graphics.yaml`.                                                                                                                                                                 |
| ROOMS-4      | Rooms must specify a wall tile. Wall tile must reference `graphics.yaml`.                                                                                                                                                                   |
| ROOMS-5      | Rooms must specify entities and items that can spawn, with probabilities. Probabilities must be defined for each entity and item.                                                                                                             |
| ROOMS-6      | Rooms must be encased in outer walls. Outer walls are defined by the base level.                                                                                                                                                              |
| LEVELS-1     | Levels are the playable areas in the game. Levels can be procedurally generated or predefined.                                                                                                                                                |
| LEVELS-2     | Procedurally generated levels must specify minimum and maximum size. Size includes width and height.                                                                                                                                          |
| LEVELS-3     | Procedurally generated levels must specify room density. Density determines the number of rooms.                                                                                                                                              |
| LEVELS-4     | Procedurally generated levels must specify a floor tile. Floor tile must reference `graphics.yaml`.                                                                                                                                         |
| LEVELS-5     | Procedurally generated levels must specify a wall tile. Wall tile must reference `graphics.yaml`.                                                                                                                                           |
| LEVELS-6     | Predefined levels must follow a global standard format. Format includes tile layout, entity/item placements, and player starting position.                                                                                                    |
| LEVELS-7     | Levels must specify progression rules. Progression defines which level type generates at specific dungeon depth ranges.                                                                                                                       |
| METADATA-1   | Campaigns must include metadata to describe the campaign and its starting conditions. Metadata includes name, author, description, version, starting map, and player definition.                                                              |
| METADATA-2   | Metadata must specify a name. Name must be a string.                                                                                                                                                                                          |
| METADATA-3   | Metadata must specify an author. Author must be a string.                                                                                                                                                                                     |
| METADATA-4   | Metadata must specify a description. Description must be a string.                                                                                                                                                                            |
| METADATA-5   | Metadata must specify a version. Version must be a string.                                                                                                                                                                                    |
| METADATA-6   | Metadata must specify a starting map. Starting map is optional and references a map type or predefined level.                                                                                                                                 |
| METADATA-7   | Metadata must specify a starting player definition. Starting player definition is optional and references a player entity.                                                                                                                    |
| RULES-1      | Campaigns are self-contained and do not rely on global settings or scripts. Campaigns must load all stats, graphics, and configurations from their own data.                                                                                  |
| RULES-2      | All stats, graphics, and configurations are loaded from the campaign. Campaigns cannot reference global settings.                                                                                                                             |
| RULES-3      | Campaigns are data-only and do not include custom scripts or behaviors. Campaigns cannot include Lua or other scripting languages.                                                                                                            |
| STATS-1      | Stats must include XP and Levels. XP tracks experience points, and Levels are derived from XP.                                                                                                                                                |
