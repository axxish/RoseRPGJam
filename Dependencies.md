# Dependencies for RoseRPG Engine

## Core Dependencies

| **Dependency**  | **Version**       | **Description**                                                                                     |
|-|--|--|
| C++              | C++17 or higher  | Core programming language for the engine.                                                          |
| raylib           | 4.0 or higher    | Library for graphics rendering and input handling.                                                 |
| CMake            | 3.27 or higher   | Build system for compiling the engine.                                                             |
| YAML-CPP         |   |                              |
                                                        

## Additional Notes
- Ensure all dependencies are properly documented and included in the build system.
- Dependencies must be compatible with Windows and Linux platforms.
